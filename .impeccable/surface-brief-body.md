# Surface brief — ID Photo Studio

Scope and visitor mode: Redesign of the single-page ID Photo Studio. Persuade leads the entry promise; the editor inherits the world while task affordances stay standard.

Audience, job, action/task, proof/content, constraints: Personal travelers. Job: turn a portrait into a print-ready ID photo, privately. Task: upload → compose → name → download. Constraints: client-side only, 300 DPI output spec, no invented claims.

Chosen direction and memorable moment: Bauhaus foundation-course workshop.

STORY: The visitor understands making an ID photo is composing a balance; believes it can be private and print-ready; does: compose, name, download.

FIRST VIEWPORT: White ground, black geometric composition; mechanism proven immediately; primary action clear.
